# U.S. Greenhouse Gas Emissions by Economic Sector, 1990–2020

**Live:** https://mentalplatypus.github.io/US-CO2-Emission-Data/

A stacked area chart of yearly U.S. greenhouse gas emissions by economic sector, made with Python, pandas and matplotlib.

Data: [U.S. EPA Greenhouse Gas Inventory](https://cfpub.epa.gov/ghgdata/inventoryexplorer/)

Part of [David Wang's portfolio](https://mentalplatypus.github.io/).
